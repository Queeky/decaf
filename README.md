## DecaffeinatedGames.com

Decaf Games is a hub for browser-based, multiplayer word games + whatever else I thought would be funny, with a visual layout that shares the vibe of 2005 Dunkin Donuts.

Features that exist (more are incoming): 
- Run-Away Story
- Pixel Garden

You may notice you require a password to enter Decaf Games. This is because the site is still in beta; it will be public soon.
